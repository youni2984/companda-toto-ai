# 컴판다 토토 AI사전 분석

기존 컴판다 서비스와 같은 내용과 기능으로 개발할 새 프로젝트입니다.

## 현재 상태

- GitHub 저장소 생성 및 쓰기 권한 확인 완료.
- 현재 커밋은 개발 안내와 민감 파일 제외 설정만 포함합니다.
- 실행 가능한 사이트, 실시간 데이터 수집, AI 분석, 카카오톡 전송은 아직 구현하거나 배포하지 않았습니다.
- 원본 프로젝트 소스를 확보한 뒤 기존 구현과 데이터 연결 방식을 확인해야 합니다.

## 유지할 기능

1. 축구 / 야구 / 농구 / 배구 / 골프 / 토토 U/O 종목 메뉴.
2. 종목별 현재·이전 회차, 경기번호, 한국시간 경기시각, 대진, 시장과 기준점, 배당, 경기 상태.
3. 사용자 입장 및 새로고침 시 데이터 재조회. 실패 시 기존 자료를 최신 자료로 표시하지 않음.
4. 최근 5~10경기 동일 표본 비교, 맞대결과 홈·원정 및 선수·라인업 자료 기반 참고 분석.
5. 조회 경기 수, 검증 통과 예상픽 수, 선택 수, 보류 수, 미제공 수의 실제 행 기준 집계.
6. 주력·부주력·고배당·초고배당·수동 티켓과 선택 추가·제거.
7. SCORECENTER LIVE 공통 티켓 형식, 기본 가상 기준금액 5,000원.
8. 카카오톡 공유 문구와 실제 SDK 연동 상태를 구분. 확인되지 않은 전송을 완료로 표시하지 않음.
9. 과거 회차의 결과·저장된 사전픽·적중/미적중/미제공/미확인 판정.
10. 모바일 가독성과 조작 편의성.

## 추천 검증 원칙

판매 중이며 시작 전인 경기, 현재 회차와 경기번호가 일치하는 데이터만 추천 대상으로 검토합니다.
기본 추천 후보는 시작까지 2~4시간인 경기입니다.
라인업 등 필수 자료가 누락되거나 선택픽 검증 표본이 부족하면 보류합니다.
통계 보조지수를 적중확률로 표현하지 않고, 취소·연기 경기와 같은 경기의 상관 선택을 티켓에서 제외합니다.
검증을 통과한 경기가 부족하면 추천 없음으로 표시합니다.
백엔드가 반환한 티켓과 픽도 별도로 검증합니다.
적중을 보장하거나 실제 구매·결제를 수행하지 않습니다.

## 원본 소스 확인 후 진행

원본 프로젝트의 실행 방법, 데이터 제공자, 서버 API, 저장소 구조, 인증 방식과 공유 연동을 확인합니다.
사용자 정보·저장된 기록·서버 설정은 소스 코드와 별도로 취급합니다.
API 키, 비밀번호, 인증 쿠키, 사용자 계정 및 운영 데이터는 커밋하지 않습니다.
원본 코드에 민감 값이 포함되어 있으면 GitHub에 올리기 전에 제거하고 환경변수로 분리합니다.

원본 소스가 준비되면 기능을 구현하고 적절한 검사와 모바일 화면 확인 후 배포합니다.
